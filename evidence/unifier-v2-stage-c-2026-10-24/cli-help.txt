$ python3 tools/unifier.py view --help
usage: ml view [-h] {open,list,status,revoke,recover,readlink-raw} ...

positional arguments:
  {open,list,status,revoke,recover,readlink-raw}
    open                mount a read-only view without starting the
                        environment
    list                list view leases and their liveness
    status              show one view or all views
    revoke              stop the worker/broker, unmount and release the view
                        lease
    recover             clean stale view records without lazy unmount
    readlink-raw        return the raw stored symlink text through the view
                        control socket

options:
  -h, --help            show this help message and exit
