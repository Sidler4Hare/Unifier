# 文件与执行上下文探针

2026-10-23，设计研究中的最小实测，不是产品整体通过报告。

- [原始结果](result.json)：真实 argv、镜像 digest、输出、源码哈希、清理结果。
- [一致性核验](validation.json)：13 项实测输出、源码未变、清理与文档链接检查；不代表新架构已实现。
- [可重跑脚本](probe.py)：从本项目锁文件选择本地镜像，不下载、不安装包、不操作已有容器。
- [架构复审](../../设计/宿主权威与文件执行边界.md)：结论、现状差距、建议契约与后续验收矩阵。

运行：`python3 evidence/architecture-context-2026-10-23/probe.py --output /新的绝对路径/result.json`。输出已存在时拒绝覆盖。

结果：host + Debian + Fedora + Arch 四次脚本执行均退出 0。共享脚本 inode 相同，shell 与绝对 symlink 解析跟随执行环境。仅宿主有 Python，三套基础镜像都没有，未发生宿主补位。测试文件内容/权限/属主/xattrs 与容器集合前后一致；临时容器已清理。

实验显式使用只读根、只读测试目录、无网络、`keep-id`、`label=disable`。后者避免对宿主测试目录重标记，不表示产品应默认关闭容器 SELinux 分离。没有验证 GUI、Python 跨发行版包、文件回写、Portal 文档授权或恶意程序隔离。

纯函数观察：当前 `creation_argv()` 对普通目录生成 `:z`；`_shared_workdir()` 接受带 `..` 的共享前缀字符串。这是当前工作树行为记录，不是宿主越权利用证明。当前源码哈希见结果文件。
