# Unifier v0.0.7

本版以 [v0.0.6](v0.0.6.md) 为基线，收口 Debian 13、Fedora 44 和 Arch 的包管理，接入统一文件访问与授权。正式包从已验收的 `0.0.7.dev0` 候选提升，仅改产品版本号。候选 SHA-256 为 `7f99118f0a34d10df73b8f94624ce3119679f8fc3e11acb4d218f7aa5f1a4a2b`。

- 三目标支持停止态包清单、原生包事务和显式恢复。Fedora 读取 RPM SQLite 需要宿主 Python 提供 `rpm` 模块。[实现边界](三目标包管理收口-20261112.md)
- 文件选择器、项目、复制移动和只读投影共用权限判断。未共享文件经 Portal 交付时提供只读副本，宿主可用 `unifier file access revoke` 回收。已打开的描述符和已经读取的内容有各自的生命周期。[统一文件访问](统一文件访问与权限系统-20261113.md)

候选完成独立解包检查与私有入口的 `0.0.6 → 0.0.7.dev0 → 0.0.6` 演练。在隔离 Debian 13 的 Zenity 中通过 GTK Portal 选择并读取测试文件，撤销后再次打开同一路径返回 `ENOENT`。三目标原生事务和写入中断恢复按固定实例实证，范围见 [当前状态](当前状态.md)。实机原始回执存于仓库 `artifacts/v007-candidate-20261114T142129+0800-JZE0NirY/portal-real-X3DO8HSw/report.md`。

从 0.0.6 升级及回退遵循 [安装说明](v0.0.1.md)。版本化代码目录与日用数据目录分别保留。
