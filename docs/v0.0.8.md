# Unifier v0.0.8 正式版

发布日期为 2026-11-23。仓库标签为 `v0.0.8`，CLI 版本为 `0.0.8`。正式归档、逐文件清单和 SHA-256 放在同一个 GitHub Release 中。[下载 v0.0.8](https://github.com/Sidler4Hare/Unifier/releases/tag/v0.0.8)

## 变更

- 统一重构后的运行时、应用租约和分层模块。保留现有启动登记、命令入口、JSON 与原生命令退出码的兼容路径。
- 保留 Debian 13、Fedora 44 与 Arch 的原生包流程，继续提供安装诊断、事务记录和恢复。客体资格与宿主派系按项目白名单核验。
- 桌面集成包含宿主 GTK、Qt 文件选择器、PipeWire 客户端补齐、显式摄像头和渲染节点配置。WPS 的四项已核验适配资源随正式归档提供。
- 继续提供文件授权和撤销、只读投影、项目会话及精确取消。开源 CLI 与文件操作仍使用统一的管理根和身份绑定。

## 安装与升级

在一处下载 `unifier-0.0.8.tar.gz` 和同名 `.sha256`，校验后解包。

```sh
sha256sum -c unifier-0.0.8.tar.gz.sha256
tar -xzf unifier-0.0.8.tar.gz
cd unifier-0.0.8
python3 tools/install_unifier.py
unifier --version
```

已有用户级命令可在应用正常退出后使用 `python3 tools/install_unifier.py --upgrade`。脚本切换 CLI 链接并生成回退链接。已有固定路径的桌面菜单及双击安装入口需核对其调用的代码目录，按原登记方式切换前保全各自文件。环境、程序登记和项目数据沿用其原有状态根。完整命令、安装及回退操作见 [安装说明](v0.0.1.md)和[首次配置](../设计/CLI首次配置与发行版专用目录-2026-10-29.md)。
