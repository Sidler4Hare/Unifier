# Unifier v0.0.6 补丁

基于正式 v0.0.5，保留原生 Portal 文件交付、超时、消息预算和交付进程恢复修复。仅增加前台应用辅助进程退出策略；不合入另一个工作树中的无关增量。

`unifier app add <环境> <新应用ID> --exec <前台命令> --on-demand --exit-policy stop-children` 仅用于会一直等待界面结束的命令。主命令退出后，监督者向该执行拥有的辅助进程发送TERM，继续核验PID/starttime/pidfd并等待全部后代回收。10秒后实际使用KILL时，原主命令成功也返回125，保留原始退出码和升级标志。默认wait及现有登记不变；不得给提前返回的后台启动器启用此策略。策略变化纳入handler执行指纹。

本轮固定Debian/WPS 12.1.2.29183整合模式已经完成两轮编辑保存/重开、三次关闭，CLI持续运行，最后租约自动停止原容器。全部后台收尾使用TERM，没有KILL。该GUI证据来自修复工作树；发布包另做独立解包全仓检查和安装入口检查。字体/版式、账号云同步、其他目标和长压力不由本次验收。

发布回执、SHA-256及条件回滚脚本记录在 ~/.local/share/unifier-code/packages/0.0.6/release.json。安装入口切换后，新启动采用本版；已经运行的应用/桥接继续原代码，不自动重启。旧v0.0.5代码和包保留。

本机部署与精确回退记录位于仓库的 `artifacts/release-v0.0.6-20261112/report.md`，WPS 实测原始回执位于 `artifacts/wps-close-regression-20261112/report.md`。
