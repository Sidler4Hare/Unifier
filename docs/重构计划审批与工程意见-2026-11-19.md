## 六项工程意见的处理

1. **分别校对暂存快照与发行包。** 同一源码树的历史暂存快照共 1,224 项，1,219 通过、5 跳过。`.desktop.1` 独立候选共 1,224 项，1,214 通过、10 跳过。候选日志有 4 次 `ResourceWarning`，其中 2 次涉及子进程、2 次涉及 SQLite 连接。每个对象分别核对总数、通过数、跳过原因和关键用例名称。合并或替换旧用例时登记新旧对应关系。[暂存快照日志](../artifacts/git-desktop-checkpoint-20261119T194859-s_vnh2og/staged-desktop/command.log#L115) · [候选验证日志](../artifacts/git-desktop-checkpoint-20261119T194859-s_vnh2og/release/unifier-0.0.8b1+render.1.portal.2.install.1.media.1.desktop.1.tar.gz.validation.log#L99)
2. **按调用方决定去留。** `read_inventory_readonly` 是包服务通过 `getattr` 调用的正式接口，列入保护清单。`screencast` 随现役探针及其测试处理，`loader_verification.verify_fixture_loading()` 在 v0.0.8 保留公开诊断入口。两份旧视图实现共 1,022 行，退役前核对旧 `python -m` 参数、别名、readlink、inode 和替代入口。15 个符号和 2 个方法逐名复核。[产品调用](../src/unifier/service.py#L2795) · [诊断 API](自动依赖与原生安装交互.md) · [删除与迁移清单](../设计/代码重构方向与精简工程-2026-11-19.md#删除与迁移清单)
3. **按三种口径结算精简。** 基线为产品 Python 35,314 行。原估算分项合计 2,293～2,443 行，含 899 行拟迁移模块。降到 32,700 行需实际净减 2,614 行。第二批按实际去留重估，正式版分别报告产品目录净减、全仓真正删除与新增、发行包变化。拆文件记录为结构调整。[精简口径](../设计/代码重构方向与精简工程-2026-11-19.md#精简口径)
4. **以还原后的状态验收备份。** 在临时目录组合 Git 对象、索引与工作树，逐项核对脏文件、模式与链接。`artifacts/` 当前有 1,391 条受跟踪路径，按索引和工作树恢复。对未跟踪的候选原包、WPS 输入和关键回执，保存字节或核验独立副本。[备份与恢复演练](../设计/代码重构方向与精简工程-2026-11-19.md#备份与恢复演练)
5. **按写入文件和锁拆分改动。** 第二批串行处理同一 `projection.py` 上的删除与去重，照顾旁支对 `_mnt_id` 的导入。会话与视图检查由服务在锁内执行。第三批分别保留包事务和应用安装的可回退差异，第四批处理厂商规则。摄像头和 GPU 分别核验租约、非阻塞包锁和生命周期锁。[删除入口](../src/unifier/service.py#L1135) · [设备配置](../src/unifier/service.py#L908)
6. **把用户工作流写入正式版放行条件。** 第三批覆盖三目标路由及 Leap 创建拒绝，第四批验证通用协议和原软件，最后一批在候选上验证旧记录、升级和回退。本版用原有 CLI 文案、JSON、退出码和桥协议断言校对行为。217 处文案断言的整体迁移单列设计。[三目标接口](../设计/v0.0.8-硬件专项与v0.0.9准备.md#7-为-v009-准备什么) · [桌面验收组合](../设计/宿主桌面与硬件接口适配计划-2026-11-19.md#验收组合和放行判据)
