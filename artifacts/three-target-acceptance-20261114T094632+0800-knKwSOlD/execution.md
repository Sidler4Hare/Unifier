# 三目标实机验收

范围为既有 Debian 13、Fedora 44 和 Arch 测试实例。每次仅一个工作负载，先验证当前开发树，再按固定实例保护器准入。没有发布或日常安装变更。记录限额、源码与实例基线、每一步通过条件和原始收尾证据。

T1 使用 `tools/offline_test_guard.py`，512 MiB、96 tasks、1 CPU、swap 0、300 秒，单独监督 64 MiB/16 tasks。私有 HOME/XDG/TMP，无容器、无 GUI。T2/T3 另按各阶段记录准入、回退与实际数值。通过证据必须包含原生退出、数据库与登记清单、恢复屏障、进程和实例收尾。

## 私有桌面

从已签名的发行版包准备私有 Xvfb，不安装宿主包。窗口为无账号、无媒体设备的合成小应用。以私有 XDG 软件列表运行正式 adopt/install 与菜单出口，Xvfb 无 TCP 监听。只把本轮随机认证的 X11 流通过既有测试共享目录中的 Unix socket 送入容器。保持原容器挂载、硬配额和日常桌面。Arch 用一次性私有 keyring 验证合成包签名，仓库正常签名策略和宿主/客体持久信任库不改。检查窗口标题、正常关闭、应用树回收、租约撤销、实例恢复停止，再移除本轮合成包及菜单项。每阶段独立预算，源码与测试包摘要留存。
