# v0.0.3 执行范围

目标：汇总当前增量，增加错误日志驱动的依赖诊断/补库入口，构建并独立验证 v0.0.3。
允许：新诊断模块及相关测试；CLI/service 连接；版本和现行文档；源码包构建器。
禁止：容器创建/启动/挂载/exec、GUI/桌面、原生包事务、宿主配置、发布/推送、删除历史数据或证据。
每批 T1：512 MiB/96 tasks/1 CPU/0 swap，独立保护器64 MiB/16 tasks，250ms采样，1GiB宿主保留量，30秒准入，每批最多300秒。
Qwen 仅有界编辑，不运行测试；主控独立审查与测试。保护触发不自动重试。
停止条件：定向及全量离线和独立解包检查通过，输出包、校验、清单、回执及未验收项后结束。
