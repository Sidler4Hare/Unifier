# 包事务与统一文件访问系统回执

2026-11-13；主工作树 0.0.7.dev0。用户本轮要求先修包事务，再完成文件访问与权限系统的设计及代码落地。保留每发行版一个共享容器和一套原生包数据库；未创建应用专属容器或引入重复依赖同步。

## 实现

包事务以目标环境的 UUID/generation/CID、原生命令、真实清单和最终验证决定结果。非目标环境与宿主的观察独立写入 `isolation_observation`：`unchanged / changed / unavailable`，归因固定为 `unattributed`。运行态同伴无法只读取清单、宿主观察失败或外部桌面条目变化不会推翻已验证的目标成功；CLI 仍输出审计警告。无法观察的条目不以空列表伪造增加/删除。目标代际替换、原生命令失败、中断状态与恢复屏障继续拒绝，不提供虚假的包数据库原子回滚。

新增 `file_access.py`、`file_access_store.py`、`file_access_cli.py`，统一用途、根范围、拒绝路径、静态映射和后端能力。五种 Portal 模式走同一个交付桥；命令选择器消费已交付客体 URI。FileRef、项目会话、复制/移动、源清理与只读投影均接入共同策略，同时保留各自已有的 FD、实例和事务核验。

选择授权账本独立放在宿主私有目录，记录环境 binding、进程身份、策略版本、源身份、目录 inode、预算和状态；先预留，后物化，最后公布 URI。复制失败、撤销失败、对象替换、无凭据的目录消失均不虚报释放。私有 FD 的协议 2 就绪通知替代审计日志控制；旧存活桥不强制升级。新增 `file access policy/list/revoke/recover`，支持版本比较、显式撤销、死租约精确恢复和幂等收尾。已有静态挂载与新增挂载都不能与策略矛盾，且不得共享权限账本。

完整契约、命令和能力边界见 [设计与实现](../../docs/统一文件访问与权限系统-20261113.md)。策略管理后续授权，不自动收回旧会话、FD 或已读取数据；静态挂载是环境级权限。未共享文件是初始 0400 的副本，不是同 UID 下不可变的对象，不写回原件；未共享保存/目录仍明确拒绝。

## 保全与收尾

全部测试通过统一 T1 运行器串行执行：工作进程树 512 MiB / 96 tasks / 1 CPU / swap 0，独立监督 64 MiB / 16 tasks，宿主保留线 1 GiB。最终全仓作业内存峰值约 171 MiB，任务峰值 19；最低宿主可用内存约 3.19 GiB，命令退出 0、无保护中止、测试 cgroup 和私有临时目录均已移除。没有使用活动显示、会话 DBus、用户键鼠、容器或全局资源调整。私有 DBus 子进程由测试和保护器收尾；不将测试退出等同于 GUI 验收。

`before/` 与 `changes.patch` 保留本轮增量的恢复依据；Portal 历史文档仅追加带日期说明，其原文可由增量移除恢复。`preservation.json` 记录当前修改文件哈希以及 Git 索引未变。原脏改动、原索引、事务/租约和历史中止证据保留。源码没有提交、推送、打包或部署；日常安装入口未修改。

本轮没有调用真实 runtime；新增项目容器动作 0。没有主动盘点运行容器或采集桌面身份，因此不声称已现场核验全部日常应用状态。未进入任何真实包事务，也不存在需要本轮对真实数据库执行的恢复。
