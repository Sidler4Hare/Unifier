usage: ml [-h] {env,pkg,app,root,file,res} ...

Lifecycle, package, desktop and resource commands for Debian, Fedora and Arch
environments.

positional arguments:
  {env,pkg,app,root,file,res}
    env                 create, inspect and run a project-owned environment
    pkg                 query, install, update and remove native packages
    app                 record and open an application inside an environment
    root                register independent host data roots
    file                resolve a read-only FileRef inside a registered data
                        root
    res                 sample cgroup, PSS, disk and host resources

options:
  -h, --help            show this help message and exit

usage: ml env [-h]
              {create,list,inspect,export,start,stop,remove,plan,migrate,run} ...

positional arguments:
  {create,list,inspect,export,start,stop,remove,plan,migrate,run}
    create              create a stopped environment from the locked image
    list                list environments recorded by this project
    inspect             show one environment record and live runtime state
    export              write the inspect record to a JSON file
    start               start an environment's sleeper process
    stop                stop an environment without deleting it
    remove              delete an environment and its writable root
    plan                show whether a change upgrades this environment or
                        replaces it
    migrate             explicitly add versioned identity to one valid legacy
                        record (no runtime calls)
    run                 execute argv in a started environment

options:
  -h, --help            show this help message and exit

usage: ml root [-h] {add,list,show,remove,match} ...

positional arguments:
  {add,list,show,remove,match}
    add                 register a local host directory; never mounts it
    list                list data-root registrations
    show                show one registration by UUID or locator
    remove              remove only the registration; the directory is never
                        deleted
    match               select the longest registered root for an absolute
                        path

options:
  -h, --help            show this help message and exit

usage: ml file resolve [-h] [--path ABSOLUTE_PATH] [--role ROLE]
                       [root] [relative]

positional arguments:
  root                  root UUID
  relative              path relative to that root

options:
  -h, --help            show this help message and exit
  --path ABSOLUTE_PATH  select the longest registered root for this absolute
                        path
  --role ROLE           bounded file-role label; never an interpreter selector
