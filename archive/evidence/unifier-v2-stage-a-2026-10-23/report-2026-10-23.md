## 本轮交付

1. **版本化环境身份**
   - 新记录 schema 2：`environment_uuid`（UUID v4）+ `generation=1`；`id` 仍是别名。
   - `env list/inspect/plan` 携带身份；只读路径不补写身份。
   - `env migrate ID` 只迁移无身份的有效 schema 1 记录；原记录备份、per-record flock、幂等、持久写入；不访问 runtime。
   - 半身份、非法 UUID/generation、schema 2 缺身份、未来 schema、broken contract、不可读 JSON 失败且零写入。

2. **应用启动绑定**
   - launch schema 2 固定 `environment_id + environment_uuid + generation + container_id`。
   - `exec_app`、`service.start(expected_binding=...)`、`supervised_open`、`managed_open`、`LaunchGroup.acquire` 在 runtime 变更前核对。
   - 同名环境删除重建后旧绑定拒绝；旧 launch 可读可删，但 open/exec 必须显式重新登记。

3. **独立数据根**
   - `.lab/state/data-roots/registry.json` + `registry.lock`，flock、临时文件、fsync、原子 rename。
   - 字段：`root_uuid`、`management_domain`、`backend`、`locator`、`access_policy`、`schema_version`、`root_dev`/`root_ino`、`created_at`。
   - 仅 `local-directory` + `host-project`，政策 `read-only`/`read-write`；未知值拒绝。
   - 重复真实路径、符号链接别名、相同 inode 保守拒绝；显式嵌套根最长组件匹配。
   - `root remove` 只移除登记，绝不删除目录；数据根不随环境删除。

4. **只读 FileRef**
   - `file resolve ROOT RELATIVE` 或 `file resolve --path ABS`。
   - 锚定根 FD 逐段 `O_PATH | O_NOFOLLOW`；拒绝所有 symlink、`..`、绝对路径重置、跨设备、根路径替换。
   - 最终 FD `fstat` 构造 `observed_version`；能力只有 `observe`；不执行、不选择解释器/环境、不做 PATH/MIME 路由。

5. **共享 workdir 登记修复**
   - 拒绝 `..`；要求已存在目录；真实路径仍位于最长匹配共享根内，拒绝符号链接逃逸。
   - 这是登记时校验，不限制环境进程后续行为。

## 已知边界与风险

- **B–F 未完成**：无停止环境只读投影/FUSE、真实 GUI 宿主项目闭环、受管复制/移动/源清理、文件 handler 执行、daemon IPC/UI、项目会话/桌面入口撤销、压力/跨宿主验收。
- **默认 `:z` 宿主目录重标记缺口未解决**。新 `root`/`file` 入口不挂载、不 relabel；没有改 `--volume` 默认策略。
- `FileRef` 仅观察/解析；没有读取内容、写入、复制、移动、删除或执行能力，不能把这些能力误标为已实现。
- `FileRef` 的根替换检测是打开前后 `stat` 对照，存在竞态窗口；它不构成全局文件系统保证，也不限制同容器其他应用或外部写入者。
- 第一版拒绝所有 symlink；没有投影链接或环境内绝对链接语义。
- 删除重建同名环境被当作新环境（新 UUID、generation 1）；同 UUID 的 generation 切换/重建编排未实现。
- 迁移只针对 schema 1 旧记录；不自动迁移真实 `.lab/state`，需要用户/验收者显式运行 `env migrate ID`。
- 没有真实 Podman 结果；真实运行验收由监督者另行安排。
