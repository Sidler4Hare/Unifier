$ python3 tools/unifier.py --help
usage: ml [-h] {env,pkg,app,root,file,res} ...

Lifecycle, package, desktop and resource commands for Debian, Fedora and Arch
environments.

positional arguments:
  {env,pkg,app,root,file,res}
    env                 create, inspect and run a project-owned environment
    pkg                 query, install, update and remove native packages
    app                 record and open an application inside an environment
    root                register independent host data roots
    file                resolve a read-only FileRef inside a registered data
                        root
    res                 sample cgroup, PSS, disk and host resources

options:
  -h, --help            show this help message and exit

$ python3 tools/unifier.py env create --help
usage: ml env create [-h] --target TARGET [--id ID] [--network {none,pasta}]
                     [--share SHARE]
                     [--share-label {preserve-host,shared-relabel}]
                     [--desktop] [--userns {rootless-default,keep-id}]
                     [--device DEVICE] [--portals] [--gpu]
                     [--ipc {private,host}]

options:
  -h, --help            show this help message and exit
  --target TARGET       debian13, fedora44 or arch
  --id ID               defaults to the target name
  --network {none,pasta}
                        none has no repository access; pasta is required for
                        install and update
  --share SHARE         absolute host directory, mounted at the same path;
                        repeatable
  --share-label {preserve-host,shared-relabel}
                        preserve-host (default) adds no :z and never relabels
                        the host; shared-relabel explicitly adds :z to
                        ordinary shares
  --desktop             mount the current Wayland, X11 and audio sockets
  --userns {rootless-default,keep-id}
                        keep-id allows applications to run with the host
                        UID/GID
  --device DEVICE       explicit /dev/videoN camera; requires --desktop
  --portals             filtered host desktop portal bridge; use an on-demand
                        application
  --gpu                 passthrough host /dev/dri devices for hardware
                        graphics and video; requires --desktop
  --ipc {private,host}  IPC namespace mode; desktop defaults to host

$ python3 tools/unifier.py root --help
usage: ml root [-h] {add,list,show,remove,match} ...

positional arguments:
  {add,list,show,remove,match}
    add                 register a local host directory; never mounts it
    list                list data-root registrations
    show                show one registration by UUID or locator
    remove              remove only the registration; the directory is never
                        deleted
    match               select the longest registered root for an absolute
                        path

options:
  -h, --help            show this help message and exit
